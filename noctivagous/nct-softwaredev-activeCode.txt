nct-softwaredev-activeCode

In what we are calling "active code" files,
the code that is available for editing
is a product of executed code so that,
for example, an object graph is in place.
The editable code is a layer.
Code has to execute in order to provide
the code that can be read by
a code editor and the execution
of that code sets up a dynamic
situation where, if the person or
an AI starts editing it, the insertion,
deletion, or addition of code
requires re-execution of the code
file(s) or portions of them
just to render and provide the
editable layer again.  The result
is that the code files provide immediate
feedback after changes are made to them
and their effects at runtime are known
and available inside the code files.
